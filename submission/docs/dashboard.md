# Dashboard and query demo

The dashboard is intentionally lightweight. The capstone assessment focuses
on the Gold contract and the downstream NL-to-SQL behavior, so a learner can
use Metabase, Streamlit, or a notebook without changing the data model.

Recommended dashboard cards:

1. Daily net revenue, orders, average order value, and refund rate.
2. Revenue and refund rate by sales channel.
3. Top campaigns by ROAS and attributed net revenue.
4. Product stockout rate and top products by units sold.
5. Active customers, repeat-customer rate, and support-contact rate.
6. Last data refresh and pipeline run identifier.

The prebuilt API exposes the same Gold layer for natural-language questions.
